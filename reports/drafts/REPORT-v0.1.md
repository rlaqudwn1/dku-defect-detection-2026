## 1. 연구 목적과 질문

본 연구는 제공된 제품 이미지와 이미지 단위 정상/불량 라벨을 이용해 이미지마다 불량 점수 하나를 산출하는 문제를 다룬다.0은 정상,1은 불량이며 높은 점수가 불량을 나타낸다. 사진에 여러 제품이 있어도 출력은 하나다. 모델이 출력하는 sigmoid 점수는 확률 보정이 확인된 값이 아니므로 본문에서는 불량 점수라고 부른다.[C001, C006]

여러 외형·입력 크기가 섞인 데이터에서 판독 가능한 정보, 제품·촬영 관계, 라벨과의 연관 및 검증 노출을 먼저 확인하고, 제한된 계산 자원에서 기준 모델의 성능과 비용을 측정하는 것을 목표로 한다. 현재 같은 실물의 정상·불량 전후 쌍이나 공식 제품 범주가 확인된 것은 아니다.[C007]

연구 질문은 다음과 같다.

1. 관측 차이는 정의·표시 조건·정보 부족 중 무엇으로 설명되는가?
2. 실제 입력 변환 후 판별에 필요한 정보가 남으며, 모델 성능·비용에 어떤 차이가 있는가?
3. 제품 외형·촬영 관계를 고려한 검증은 어떤 일반화를 평가하는가?
4. 허용된 현대적 표현의 단순 지도 분류는 어떤 성능·비용·실패를 보이며, 어떤 관측이 국소 집계·미세조정 등 추가 비교를 정당화하는가? 같은 backbone의 초기화 비교와 불균형 처리는 별도 질문이 있을 때 검토한다.

이 질문은 아직 검증된 결론이 아니다. 연구자의 직관과 모델·전문가의 해석 모두 가설로 기록하고, 구분할 관측·반례·실패 조건을 함께 남긴다.

## 2. 관련 연구 — 초기 범위

ResNet은 잔차 학습을 사용하는 이미지 인식 구조이며 현재 기준선의 구조 출처다.[S01] AdamW는 weight decay를 gradient 기반 갱신과 분리하는 최적화 방법으로 현재 학습 구현에 사용된다.[S02] 이 문헌들의 결과를 우리 데이터의 성능으로 옮기지 않는다.

ResNet18은 구현된 단순 기준선 후보이며 최신 주력 모델이나 연구 기여로 채택하지 않았다. 구현의 존재와 실제 실험 수행은 구분한다. 최신 후보와의 비교는 후속 문헌·규정·자원 확인을 거쳐 설계하며, 같은 ResNet18의 초기화 비교만으로 현대적 표현의 유효성을 결론짓지 않는다. 최종 제목도 실제 수행한 연구 범위에 맞춰 수정한다.[C006, C009]

정상 특징 분포·memory bank·특징 복원·불량 감독 학습·국소 집계는 서로 다른 대안이다. PaDiM/PatchCore, AnomalyDINO/Dinomaly, DRA/SuperSimpleNet 등을 조사했으나 현재 기준선에 구현·실험한 것으로 기술하지 않는다. 관련 연구의 출판 버전·코드·감독·추가 데이터·실패 조건은 [기존 논문 안내](../../docs/research/INDUSTRIAL-DEFECT-PAPER-GUIDE.md)와 비공개Pro 원문에 보존되어 있다. 원고에 실제 인용할 후보는 원문과 출판 메타데이터를 다시 연결한 뒤 참고문헌을 확장한다.

EDA는 데이터의 구조·이상 관측·분석 가정을 확인하는 접근이다.[S04] 방법 논문의 ablation이나 오류 분석과 표본설계·관측 일치의 일반 방법론은 구분한다. 외부 원문에 있는 분석, 일반 방법론의 근거, 우리 데이터에 대한 제안은 [EDA 조사 계획](../../docs/research/IMAGE-DATA-AUDIT-PLAN.md)과 후속 검토를 통해 별도로 관리한다.

현재 조정 전 관측에서 제품 하나37장·복수 제품11장, 자국 후보seen23장·unclear25장이 기록되어 있다. 이는 첫 판독자의 표본 응답 수이며 전체 데이터의 빈도·실제 결함 수로 해석하지 않는다. 이 관측으로 정의한 특성의 후속 요약도 탐색과 확인을 구분한다.[C005]

### 3.1 조사 노출과 미확인

원본 byte 검사·기술 통계 열람·블라인드 의미 판독·라벨 대조·모델 피드백·생성 참조·학습을 구분해 기록한다. 상세히 살핀 표본을 새seed로 나눴다고 완전 미관측 검증이 되지는 않는다. 같은 실물/파생물 관계와 최종 일반화 목표는 아직 확인해야 한다.[C007]

## 4. 기준 모델 구현 — 실제 대회 학습 전

현재 구현은 전체 이미지 한 장을 입력받는 torchvision ResNet18과1-logit 선형 head를 사용한다. 기본은 `weights=None`의 무작위 초기화다. 로컬 사전학습 가중치의 provenance 필드·기재 날짜·파일 해시를 검사하는 선택 경로가 있다. 공개일·라이선스 사실 자체를 외부에서 자동 검증하는 기능은 아니며, 자산 채택 전 별도 확인이 필요하다. 대회용 가중치를 채택하거나 성능을 검증하지 않았다.[C006]

입력은 EXIF 방향 보정,RGB 변환, 종횡비 유지bilinear resize, 중앙 검정pad와 고정 채널 정규화를 거친다. 시작 설정의 입력 크기는256, batch16, epochs3, seed42다. 이 수치는 측정으로 선택한 최적값이 아니다. ImageNet 정규화 사용은 ImageNet 사전학습 사용을 뜻하지 않는다.[C006]

학습 손실은 가중치 없는 binary cross entropy with logits이고 optimizer는AdamW다. 학습 loader의shuffle은 클래스 균형 샘플링과 다르다. 현재 구현에 paired 입력, MIL, normal-only memory bank, 생성 증강을 사용한 것으로 쓰지 않는다.[C006]

### 4.1 아직 확정하지 않은 분할

기존split은 후보이며 촬영 독립성이 검증된 최종 분할이 아니다. 분할기는 바이트 중복/전달된 그룹을 함께 배치하지만mixed-label 그룹을 거부한다. 정상·불량을 함께 포함하는 실제 촬영 그룹이 확인된다면, 그룹을 쪼개지 않고 분할기 수정과 별도 검토가 필요하다.[C007]

### 4.2 평가 계획

주 지표는 전체 검증 예측의 이미지 AUROC다. 양성은불량1이다. AUROC와 threshold 기반 정확도·재현율·정밀도는 다른 질문에 답한다.[S03] 현재 대회 데이터의 실제 예측이나AUROC 결과는 없다.[C008]

검증AUROC로best checkpoint를 선택하는 구현이므로 같은검증 예측은 학습 적합 밖일 수 있어도 모델 선택 밖의 독립 확인은 아니다. 선택/확인 분할·노출·튜닝 횟수와 그룹 근거를 확정한 뒤 결과를 해석한다.[C007]

## 5. 현재 결과와 향후 실험

### 5.1 현재 보고 가능한 결과

현재 보고 가능한 결과는3절의 카탈로그·기술 관측 범위와 도구 기능 확인이다. 작은 합성 이미지CPU에서 학습·평가·재개 기능을 확인한 기록은 실제 대회 성능이 아니다. 노트북 그래프와 익명 사진 열람 역시 새 판독·모델 성능을 만들지 않는다.[C008]

### 5.2 성능 결과표 — 미측정

| 비교 | 실제 run | 검증AUROC | 시간/VRAM | 현재 상태 |
|---|---|---|---|---|
| scratch ResNet18 | 없음 | 미측정 | 미측정 | 실행 전 |
| 동결/미세조정 | 없음 | 미측정 | 미측정 | 가중치 허용 확인 후 후보 |

## 6. 현재 한계와 반례

- 원본의 readable 상태와 결함이 보이는 상태가 다르다. 자국 후보·반사·정상 무늬의 구분은 조정 중이다.
- 제품군/촬영 관계/실물 쌍이 미확인이므로 paired 학습이나 새 제품 일반화를 전제할 수 없다.
- 층화 표본의 가중 요약, 판독 측정 불확실성, 미래 촬영 일반화는 별도 문제다.
- 제품 종류·해상도·배경의 라벨 연관을 모델의 인과적 의존으로 확정할 수 없다.
- 불균형 약8:1이 특정 증강·다운샘플링의 우수성을 보장하지 않는다.
- 현재GPU 비용·대회 성능·허용 가중치 최종 선택·원격 저장/새 환경 복구는 미검증이다.

## 7. 다음 작업과 결론 작성 조건

다음은 원응답·표시 조건을 고정하고 지정16장 교차표와9건 조정표를 분리해, 정의 수정 영향만 재확인하는 것이다. 이어 실제 입력 정보보존과 필요한 관계 감사를 수행하고 평가 목표·분할을 정한다. 실제 기준선/대안의 지표와 실패를 확보한 뒤 최종 방법·결과·초록·결론을 쓴다.[C009]

**최종 결론은 미작성이다.** 현재는 데이터 감사와 재현 가능한 기준선 연구를 준비한 범위만 주장한다.
