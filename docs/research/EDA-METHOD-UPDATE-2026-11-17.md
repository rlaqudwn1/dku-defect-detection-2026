# 이미지 EDA 방법론 최신성 점검

기준일: 2026-11-17. 질문은 현재의 조사 방법이 적절한지, 어떤 최신 기법을 다음에 검토할지다. 방법·평가·도구 원문만 조사했다. 외부 원본 데이터·이미지·라벨·가중치는 조회/다운로드하지 않았다.

## 판단

현재의 무결성 검사·고정 층화 표본·블라인드 기술 관찰·불확실성·촬영 관계·입력 정보 보존 조사는 최신 연구가 다루는 문제와 맞는다. 다만 최신 자동 큐레이션을 구현했다거나 최고 성능 모델을 확보한 상태는 아니다. 48/240은 작업량 계획이며 논문이 그 수의 충분성·독립성·결함 탐지율을 입증하지 않는다.

문제 설정·출판 정보/공식 기능 설명은 원문에서 확인한 A급 근거다. CleanPatrick/AnomalyDINO의 비교 결과는 자체 평가·도메인/학습 설정 차이가 있는 B급 참고자료로만 취급한다. 특정 기법의 우월성이나 우리 성능 개선을 채택 근거로 삼지 않는다. 진행자가 결정적 원문을 다시 열어 관련 절을 확인했다.

## 다음 적용 순서

1. 작은 표본에서 판독 용어와 미확인 처리를 보정한다. 시트의 인상과 원본 사본 관측을 분리한다.
2. 실제 엔진의 resize/pad 경로로 작은 정보·경계 보존을 비교한다. 입력 크기는 시각 검사만으로 최종 확정하지 않는다.
3. pHash/픽셀 유사도와 필요 시 로컬 표현 기반 검색으로 관계 후보를 넓힌다. 서로 다른 검색법과 후보 밖 쌍도 검토하고, 동일 개체/제품 종류/판단 불가를 구분한다.
4. encoder가 필요하면 정확한 버전·출처·라이선스·SHA-256과 2026-11-15 이전 공개 여부부터 확인한다. 도구 기본 모델 자동 다운로드는 하지 않는다.

지금은 판독 기준과 정보 보존 조사에 우선순위를 둔다. 대형 VLM·새 학습기·새 저장 플랫폼의 도입은 보류한다. 패키지는 검증한 버전을 유지하며 이번 조사는 모든 라이브러리의 최신 배포 버전을 확인하거나 업데이트한 작업이 아니다.

## 검색 범위와 남은 검증

industrial visual anomaly detection, image dataset auditing, data-centric visual inspection, near-duplicate/split leakage로 검색했고 2026년 출판/개정 원고를 포함해 최근 12개월을 확인했다. 강한 원문의 관련 방법을 따라 feature/patch matching과 공식 후보 검색 문서를 검토했다. 모든 2026년 논문·최신 순위를 조사한 것은 아니다.

Real-IAD Variety와 2026 geospatial leakage 문헌도 검색됐지만 본문 접근 제한/초록 범위여서 결정적 근거에서 제외했다. 대회 데이터 출처를 역추적하거나 외부 라벨을 확인하지 않았다. 실제 도구 도입·가중치 적격성·시간/메모리·우리 검증 성능은 후속 실험이 필요하다.
