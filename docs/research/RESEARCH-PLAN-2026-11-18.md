# 정상·불량 이미지 분류 연구 계획 v1

작성일: 2026-11-18. 이 문서는 현재 질문과 작업 순서를 고정한 계획 기준본이다. 완료 결과나 최종 모델 선택 문서가 아니다. 이전 [PLAN](../PLAN.md)의 연구 범위를 유지하되, 실행 우선순위는 아래와 같이 좁힌다. 상태·원응답·실행 산출물은 비공개 장부에서 별도로 관리한다.

## 1. 현재 기법을 어떻게 부를 것인가

연구 접근은 **다제품 이미지의 정상·불량 분류에서 데이터·입력·검증 가정을 조사하고, 표현과 학습 방식을 비교하는 것**이다. 최종 주력 기법은 아직 선택하지 않았다. 현재 코드에 구현된 출발점은 **이미지 전체를 사용하는 ResNet18 지도 이진 분류 기준선 후보**다. 입력은 이미지 한 장, 감독은 제공 이미지 라벨0/1, 출력은 이미지당 불량 점수 하나다. 제품 수와 무관하게 점수는 하나다. 제품명·결함 위치를 직접 감독하는 다중 클래스/분할 모델이 아니다.

ResNet18은 오래된 구조이며 최신 성능을 대표하는 모델이나 본 연구의 기여로 제시하지 않는다. 구현 점검용 단순 비교 기준이 될 수 있지만, 현재 대회 데이터에서 실행하지 않았으므로 “실험했다”라고 쓰지 않는다. 관련 연구·서론에는 잔차 학습의 배경을 간략히 쓰고, 실제 기준선 실험을 수행하면 설정은 방법 절, 결과는 결과 절에 기록한다. 초록은 최종 연구 질문과 실제 결과를 확보한 뒤 작성한다.

주력 후보를 고를 때는 기존 문헌 조사에서 찾은 사전학습 표현의 동결/미세조정, 국소 특징·집계, 불량 감독 학습을 데이터 가설과 연결해 비교한다. 최신 연도 자체를 채택 근거로 삼지 않으며, 현대적 표현과 고전 기준선의 비교를 ResNet18 내부 초기화 비교만으로 대체하지 않는다. 실제 사용할 후보·가중치·계산 예산은 미정이다.

| 요소 | 현재 구현·설정 | 실제 검증 범위 |
|---|---|---|
| 모델 | torchvision ResNet18, 선형1-logit head | 합성 이미지 CPU 기능 경로 |
| 초기화 | 기본 무작위. provenance를 검사하는 로컬 사전학습 로딩 경로는 선택 기능 | 대회용 사전학습 가중치 채택 없음 |
| 전처리 | EXIF 보정→RGB→비율 유지 bilinear resize→중앙 검정 pad→고정 ImageNet 정규화 | 코드 경로 구현. 실제 결함 정보보존 비교 미실행 |
| 시작 입력 | 256, batch16, epochs3, seed42 | 시작 설정일 뿐 성능/학습 충분성 권장값이 아님 |
| 학습 | 가중치 없는 BCEWithLogits, AdamW, 학습 loader shuffle | 대회 데이터 학습 미실행 |
| 점수 | sigmoid 한 번으로0–1 점수 | 확률 보정 미확인 |
| 평가 | 검증 전체 예측의 이미지 AUROC, best는 검증 AUROC로 선택 | 실제 대회 AUROC 미측정 |

근거: `src/defectlab/engine.py`의 `preprocess`, `_model`, `_loader`, `_scores`, `train`과 `configs/baseline.toml`. 정확 코드·설정 hash는 실행마다 고정한다. ImageNet 정규화 사용은 ImageNet 사전학습 가중치 사용과 다르다.

현재 모델은 paired/Siamese/contrastive 학습, MIL, PatchCore·PaDiM, 생성 증강을 채택한 상태가 아니다. `anomaly_score`라는 출력 이름만으로 정상 전용 이상 탐지라고 부르지 않는다. 데이터 조사 방법은 기존 근거 재사용, 층화 표본의 기술 관측, 원응답 비교, 입력/관계/분할 가정의 검토이며 새 알고리즘 발명으로 주장하지 않는다.

## 2. 사실·가설·결정을 분리한다

| 구분 | 현재 내용 |
|---|---|
| 자료 사실 | 학습10,821장: 정상9,621/불량1,200. 테스트800장. 제공 라벨은 이미지 단위 |
| 과거 검사 기록 | 전체 이미지 카탈로그, 디코드 실패0·바이트 중복0. 후속 바이트 일치 확인 기록과 구분 |
| 기술 관측 | 첫48장, 그 일부인 지정16장 재판독. 자국 후보 응답 차이9건과 가독성 정의 조정 미완료 |
| 미확인 | 제품군 정답·실물 쌍·촬영 관계·위치/유형 정답·근접중복·최종 분할·실제 성능 |
| 결정 | 관측 규약 정리와 실제 입력 변환 비교부터 수행. 추가 표본·복잡한 모델은 조건부 |

사진에 자국이 보였다는 관측, 실제 결함이라는 판단, 제공 라벨의 근거, 모델이 이용하는 단서는 다른 주장이다. 연구자는 답을 제공하는 역할이 아니라 가설과 반례를 함께 검토한다. 진행자·사용자·전문가·Pro의 해석에 같은 근거 기준을 적용한다.

## 3. 경쟁 가설과 구분할 관측

| ID | 가설/질문 | 구분할 관측·반증 조건 | 바꿀 결정 |
|---|---|---|---|
| H1 | 9건의 차이는 주로 관측 정의 차이인가? | 당시 표시·원답변·정의 대조. 같은 정의에서도 불명하면 정보 부족 등 대안 유지 | 코드북 매핑/의미 수정/unknown |
| H2 | 작은 판별 단서가256 입력에서 약해지는가? | 같은 원본의 실제 변환 비교와 후속 모델 성능. 사람의 가시성만으로 학습 효과를 확정하지 않음 | 해상도·pad·국소 집계 후보 |
| H3 | 외형/촬영 조건과 라벨이 얽혀 있는가? | 블라인드 관측을 고정한 뒤 제품군 후보×라벨·크기·배경 대조. 연관은 인과/모델 의존의 확정이 아님 | 평가 slice·추가 진단 |
| H4 | 같은 실물/연속 촬영/파생물이 분할을 건너는가? | 관계 후보와 근거 확인. 닮음만으로 같은 개체나 전후 쌍을 확정하지 않음 | 불가분 그룹과 검증 목표 |
| H5 | 사전학습과 적응이 기준선을 개선하는가? | 동일 backbone·분할·입력에서 scratch/동결/미세조정 비교. 선택 예산과 비용 기록 | 초기 표현/학습 범위 |
| H6 | 불균형 처리 또는 생성 증강이 추가 이득을 주는가? | 하나씩 바꾸고 실제 원본 검증. 학습량·샘플링·생성 효과 분리. 반례와 비용 포함 | 가중치/샘플링/증강 채택·보류 |

“같은 종류에 정상·불량이 있다”와 “같은 실물의 전후 사진이다”는 별도 관계다. 다제품 통합 학습과 처음 보는 제품 범주로의 일반화도 다르다. 목표가 미정이면 조건별 한계를 먼저 쓰고 일반화 보장 문장을 만들지 않는다.

## 4. 단계별 실행과 완료 조건

아래 R-ID는 연구 작업 번호이며 기존 Pro 파일럿 P00–P10 장부의 stage ID를 대체하지 않는다. 계획 문서 저장을 실행 완료로 승격하지 않는다.

| 단계 | 현재 | 작업·산출물 | 완료/중단 조건 |
|---|---|---|---|
| R0 근거 연결 | 일부 확보 | 원본/카탈로그/표본/원응답의 hash·시점·검사 범위 연결 | 재사용 가능한 증거와 누락 범위 식별. 자동 전수 재실행 안 함 |
| R1 관측 기준 조정 | 다음 최소 작업 | 지정16장의 항목 교차표와9건 조정표 분리. 표기만 다르면 매핑, 의미가 바뀐 항목만48장에서 재확인 | 각 건이 해결 또는unknown+이유. 합의율 목표를 위해 반복하지 않음 |
| R2 정보보존 | 미실행 | 기존48장의 비교 가능한 영역과 실제 resize+pad 후보. 좌표·pad·가시성·불명·비용 기록 | 입력 후보를 좁힐 근거 확보. 원본에서도 불명인 영역은 보존 성공으로 세지 않음 |
| R3 관계·구성 감사 | 미완료 | 기존 통계 재사용, 필요 시 pixel/pHash→조건부 encoder. 제품군 후보×라벨은 블라인드 관측 고정 후 별도 분석 | 관계 유형·검색 범위·그룹 불확실성 명시. 추가192/발견29장은 결정에 필요할 때만 |
| R4 평가 계약 | 미확정 | 새 촬영/새 개체/새 범주/미지 결함 중 목표 명시. 그룹·노출·선택/확인 분할 고정 | 양쪽 클래스와 독립 그룹 근거. mixed-label 그룹 제약 해결 전 해당 그룹 분할 확정 금지 |
| R5 자원·첫 기준선 | 미실행 | 짧은 무료 Colab 측정, 학습/검증/저장/재개와 시간·VRAM. 대회 baseline run 생성 | 예산·재현 경로와 실제 지표. OOM·비정상 값·예산 초과면 중단/수정 |
| R6 작은 비교 | 미실행 | H5와 별도로 문헌 조사에서 현대적 사전학습 표현 후보 하나를 선정해 단순 기준선과 비교. R2 근거에 따라 해상도/집계 변경, 필요 시 불균형 처리 하나씩 비교 | 동일 평가·선택 예산. 반복 변동/비용을 넘어서는 의미 있는 차이의 기준을 결과 전에 정함 |
| R7 조건부 확장 | 미실행 | 정상 특징 비교 하나, MIL 또는SuperSimpleNet/DRA 등 질문에 맞는 후보 하나. LLM 증강은 별도 학습 전용 참조로 비교 | 실패 원인이 해당 기법을 요구할 때만. 모든 후보·앙상블을 의무 실행하지 않음 |
| R8 선택·재현·보고 | 준비 시작 | 고정 결과/실패/실제 설정/가중치·환경·예측을 연결. 새 환경 재현과 보고서 주장 검토 | 결과·한계·실제 복구 범위가 추적 가능. 제출·GPU 결제는 별도 명시 지시 |

R1과 기존 카탈로그의 최소 기술 요약은 병행할 수 있다. R2와 관계 감사도 질문에 따라 반복한다. 표는 기계적 일렬 파이프라인이 아니다. 분할 전에 조사 노출을 기록하고, 생성 참조·학습 적합은 학습 부분에 한정한다. 테스트는 무라벨 기술 속성만 조사하며 의미적 판독·정답 추정·의사라벨을 만들지 않는다.

현재 `profile`의 테스트 썸네일/원래 경로 표시 기능을 익명 train-only 판독 재개 경로로 그대로 쓰지 않는다. 현재 `make_split`은 supplied group에 라벨0/1이 섞이면 거부한다. 같은 개체의 mixed-label 그룹을 쪼개거나 relabel하여 우회하지 않는다.

## 5. 비교·중단의 공통 계약

- 주 지표는 전체 검증 예측의 이미지 AUROC다. 재현율·정밀도·정상 오탐·AP는 질문에 따라 보조로 정의하고 threshold 선택 이력을 기록한다. 미측정 값은null이다.
- 그룹·해상도·제품군 slice는 관측 수와 클래스 수를 함께 보고한다. 한쪽 라벨만 있으면 AUROC를 만들지 않는다. 표본·그룹 부족 시 억지 신뢰구간을 만들지 않는다.
- 고정할 것: 원본·분할·평가·전처리 버전, 변경 변수, 선택 횟수, 실행/자원 예산. 배치 평균 AUROC로 전체 AUROC를 대체하지 않는다.
- H5처럼 원인 해석을 위한 공통 backbone 비교와, 현대적 표현 후보를 포함해 각 방법의 적정 설정을 허용하는 실용 비교를 구분한다. 바뀐 요소를 감독량만의 효과라고 부르지 않는다.
- 수치 예산·최소 유의미 차이·seed 반복 수는 실제 자원과 그룹 구성을 본 뒤 결과 전에 정한다. 지금 임의의 성능 목표나 GPU 비용을 채우지 않는다.
- 불균형 약8:1만으로 증강·정상 감소를 확정하지 않는다. 증강과 리샘플링은 학습 분할에만 적용한다.
- 생성 증강은 무증강/일반 증강/일반+생성의 비교와 학습량 효과를 구분한다. 실제 원본 validation과 생성 reference를 분리한다.

## 6. 경계와 기록

원본/CSV·제공 라벨을 수정하지 않는다. 테스트 정답·외부 원본/라벨 조회, 외부 실제 이미지 추가 학습, 원격 모델 API 대회 예측은 금지한다. 사용자 최신 설명에 따라 연구용 이미지LLM제공·LLM증강은 허용 조건으로 적용하되 공식 규정 원문 독립 확인과 구분한다. 공개 가중치는2026-11-15까지 공개된 정확 버전·출처·라이선스·전체SHA-256 확인 뒤 사용한다.

기존 원응답·실패·중단·변경 전 계획을 보존한다. 관측/가설/결정/실행/근거 유효성/저장/새 환경 복구를 구분한다. 표본·관측 정의·표시·변환·관계·분할·노출의 버전을 분리한다. 원본·가중치·예측·키·개인 절대 경로·비공개ID·실행 출력은 Git에 넣지 않는다.
