## 구축·문헌조사·검토

- 원본 검사, 카탈로그, 후보 분할, ResNet18 학습·평가·재개·추론과 기록 도구를 구축했다. 기능 검사는 작은 합성 이미지의 CPU 경로이며 실제 대회 성능이 아니다.
- EDA 표본·판독·독립 검토·단계 재개 절차를 설계했다. P04 설계 완료는 전체 EDA 완료가 아니다.
- 산업 불량 판별의 기반 및2025/2026 문헌을 조사했다. [논문 안내](INDUSTRIAL-DEFECT-PAPER-GUIDE.md)와 [최신성 조사](EDA-METHOD-UPDATE-2026-11-17.md)에 근거와 한계를 남겼다.
- GPT-6 Pro로 연구 질문·모델 비교 방향과 EDA 방법을 두 차례 검토했다. 두 번째는 최신 로컬 문서·코드18개를 제공했다. Pro에는 두 요청 모두 실제 원본 이미지를 첨부하지 않았다.
- 연구용 이미지 제공과 LLM 증강은 사용자가 허용했다고 설명했다. 실제 이미지 생성 증강·추가 학습은 하지 않았다. 공식 규정 원문 독립 확인과 사용자 설명을 구분한다.
- 조사 의미를 설명하는 가상 와셔 포스터를 만들었다. 실제 대회 이미지나 분석 결과가 아니다.
