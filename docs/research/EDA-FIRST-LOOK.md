# 첫 EDA 표본과 판독 규약

상태: 첫 시각 조사 준비 설계. 표본 목록 생성과 실제 판독·전처리 비교·Pro 전송은 각각 별개다. 구체 설정은 [eda-first-look.json](../../configs/eda-first-look.json), 전체 조사 질문은 [이미지 조사 계획](IMAGE-DATA-AUDIT-PLAN.md)을 따른다.

## 무엇을 먼저 볼까

먼저 48장을 보며 사진을 어떤 기준으로 설명할지 맞춘다. 이후 같은 규약으로 최대 240장까지 넓히고, 드문 사례를 찾을 별도 표본은 최대 32장으로 제한한다. 이 수는 시작 작업 예산이며 통계적 충분성이나 결함 탐지율을 보장하지 않는다. 원본은 읽기 전용이며 제공 학습 이미지만 선정한다.

카탈로그에는 학습 이미지 크기 8종이 있고 각 크기에 정상/불량이 모두 있다. 라벨 2개 × 크기 8개 = 16개 묶음으로 나눈다. 이 묶음은 표본을 고르게 보기 위한 층이며 제품 종류·물리적 개체·촬영 그룹이 아니다.

| 표본 | 추출 규칙 | 목적 |
|---|---|---|
| 판독 보정 48장 | 16개 층마다 무작위 3장 | 용어·확신도·확대 보기·처리량 확인 |
| 고정 조사 240장 | 같은 층마다 무작위 15장; 보정 48장을 포함 | 조건별 특성 탐색과 제한된 빈도 요약 |
| 문제 발견 최대 32장 | 조사 240장 밖에서 밝기/색 변화 지표 극단 후보 | 드문 구성과 판독 실패 후보 발견 |

240장까지 보려면 48장 이후에 **192장만 추가**한다. seed와 정렬 규칙은 먼저 고정한다. 이미지를 본 뒤 마음에 드는 표본이 나올 때까지 seed를 바꾸지 않는다. 카탈로그·규약·추출 코드·선택된 ID와 행 순서의 해시를 저장한다. 불량을 많이 뽑기 때문에 단순 표본 비율은 전체 이미지의 비율이 아니다.

## 원본 라벨을 먼저 보지 않는 판독

첫 화면에는 익명 조사 ID와 이미지만 제공한다. 원래 파일명·라벨·모델 점수·표본 층·발견 순위는 숨긴다. 원본 연결표와 라벨은 별도 비공개 manifest에 보존하고 첫 판독 후 대조한다. 단순한 '정상인가/불량인가' 재분류를 시키지 않는다.

기록 항목은 제품 수/구성, 보이는 자국 후보와 위치, 세부 정보 가시성, 반사·가림, 판독 가능 여부, 확신도와 이유다. 각 항목에는 unclear 또는 판독 불가를 허용한다. 자국 후보는 실제 결함이라는 뜻이 아니며, 안 보인다고 정상이나 라벨 오류로 판정하지 않는다. 원래 라벨은 수정하지 않는다.

원본 확대를 기준으로 확인한다. 시트는 빠른 탐색용이고 작은 썸네일의 인상만으로 결론 내리지 않는다. 패널 안/바깥 ID는 제품을 가리지 않게 표시한다. 이번 설계에서는 이미지 파생본을 만들거나 외부로 보내지 않는다.

## 별도 재판독과 규약 보정

보정 48장 중 층마다 1장, 총 16장을 별도 판독자가 독립적으로 본다. 240장으로 확대하면 층마다 총 4장, 총 64장을 재판독한다. 이미 정한 16장을 포함해 추가 48장을 선정한다. 이 비율은 작업 예산이며 신뢰도 인증 기준이 아니다.

중요한 판독·그룹·라벨 불일치 후보는 별도로 모두 확인한다. 무작위 재판독과 분쟁 집중 판독의 불일치율을 합치지 않는다. 첫 응답·독립 응답·조정 이유를 보존하며 두 AI의 합의를 현장 결함 정답으로 쓰지 않는다. 실제 판독자가 없으면 미실행으로 남긴다.

48장에서 새 용어가 필요하면 규약 버전을 올리고 기존 판독을 같은 규약으로 재판독한다. 최초 응답은 보존한다. 이미 본 표본에서 정의한 특성의 비율은 탐색적 요약이며, 사전에 정한 가설의 독립 확인으로 주장하지 않는다.

## 문제 발견 표본의 경계

기존 카탈로그의 RGB 채널 평균의 평균과 RGB 표준편차의 평균을 사용해 낮은 쪽/높은 쪽 각 상위 8개 후보를 고른다. 같은 후보가 여러 목록에 나오면 합쳐 선정 이유를 모두 보존한다. 최대 32개이며 겹침을 채우기 위해 추가 표본을 뽑지 않는다. 정해진 240장은 제외한다.

이 지표는 밝기/색 변화의 기술적 대리 지표일 뿐이다. 흐림·노출 실패·결함·제품 종류를 확정하지 않는다. 발견 표본은 전체 발생률의 분모나 가중 추정에 합치지 않는다. 보정 48장의 판독을 마친 뒤 이 후보를 열어볼지 결정한다.

## 전처리 비교는 다음 순서

원본에서 실제로 보이는 정보를 확인한 뒤 같은 ID에 대해 현재 엔진의 비율 유지 bilinear resize·중앙 검정 pad 경로를 256/384/512 후보로 비교한다. 이미지에 정규화된 텐서를 그대로 화면 표시하지 않는다. 코드/좌표/크기·표시 규칙을 기록한다.

처음에는 crop·선명화·노이즈 제거·생성형 확대를 추가하지 않는다. 사람에게 보인다고 모델 학습 가능성을 보장하지 않으며, 원본에서도 불명인 사례는 변환 성공으로 세지 않는다. 모델 입력 크기 선택은 후속 성능·시간 실험으로 확인한다.

## 빈도 요약과 검증 노출

층별 모집단 크기 N_h, 선택 수 n_h, 포함확률 n_h/N_h와 설계 가중치 N_h/n_h를 저장한다. 보정 48장과 최종 240장의 포함확률은 각각 계산한다. 최종 조사 빈도는 층별 결과를 모집단 비중으로 합치고, 관측 수·분모·불명 수를 함께 보고한다. 조사 전에는 어떤 빈도도 채우지 않는다.

촬영 관계가 unknown이므로 독립 이미지나 독립 그룹 수를 보장하지 않는다. 신뢰구간과 그룹 수정은 관계 조사 후 정한다. 전체 카탈로그와 이 표본에 대한 노출을 기록하고, 나중에 새 seed로 재분할해도 완전 미관측 검증이 되었다고 부르지 않는다. 미래의 최종 확인용 holdout은 아직 확정하지 않는다.

## 확대·중단과 다음 행동

48장 단계에서 ID 대응, 규약의 일관성, 실제 판독 시간, 불명/불일치와 확대 보기의 유용성을 확인한다. 누락·ID 혼동이 있거나 판독 기준을 적용하기 어렵다면 먼저 자료/규약을 수정한다. 처리량이 예산을 넘으면 240장 전체 판독을 자동 실행하지 않는다. 구체 시간 예산은 짧은 판독 후 정한다.

다음 최소 행동은 선정된 48장의 로컬 원본 보기와 빈 판독 양식 연결이다. 실제 Pro 시각 분석은 대회 외부 업로드 허용·연결·모델 확인 후의 별도 선택 단계다. 이 설계로 Pro 연결이나 이미지 업로드 허용을 완료 처리하지 않는다.
