# 대회 시작 workflow 조사 — 2026-10-27

질문: 리더보드 기반 수업 과제를 가정할 때 경험 많은 참가자들의 시작 방법과 실험·데이터 분석 도구는 무엇인가? 실제 과제 형식과 데이터는 미확정이다.

판단 기준: 원 참가자의 구체적 경험, 실행 가능한 초기 단계, 데이터 유형별 적용 가능성, 팀 운영 부담. 수상 후기와 업체의 도구 소개는 인과적 성능 검증이 아닌 경험·기능의 근거로 사용한다.

- [Grandmaster 네 명의 표 형식 데이터 대회 경험](https://developer.nvidia.com/blog/the-kaggle-grandmasters-playbook-7-battle-tested-modeling-techniques-for-tabular-data/): 빠른 실험과 실제 테스트 구조에 맞춘 교차 검증을 강조한다. 시간순 데이터와 그룹 데이터의 분리 사례를 제시한다. NVIDIA 블로그이며 GPU 제품을 소개하므로 장비 필요성의 독립 근거는 아니다.
- [Grandmaster 인터뷰](https://developer.nvidia.com/blog/kaggle-grandmasters-unveil-winning-strategies-for-data-science-superpowers/): 데이터 탐색, 기본 모델, 로컬 검증, 반복 실험을 제안한다. 참가자들의 경험을 전한 업체 기사다.
- [Kaggle 대회 솔루션 색인](https://kaggle.farid.one/): 문제 유형과 평가 지표에 맞는 수상자 원문을 찾는 탐색 도구다. 색인 자체는 성능 검증이 아니다.
- [W&B 요금과 학술 라이선스](https://wandb.ai/site/pricing/), [약관](https://wandb.ai/site/terms/): 무료 및 학술 이용 조건을 확인할 수 있다. 실제 계정의 자격, 프로젝트 공개 범위와 데이터 업로드 허용 범위를 확인해야 한다.
- [MLflow 추적 문서](https://www.mlflow.org/docs/latest/tracking/): 로컬 기록과 팀용 원격 추적 서버를 지원한다. 팀 서버 운영은 별도 부담이다.
- [데이콘 대회 규정 예시](https://dacon.io/en/competitions/open/236019/overview/rules): 공개·비공개 평가, 제출 제한과 데이터·모델 사용 제한 사례다. 수업 과제에 그대로 적용된다고 볼 수 없다.

남은 확인: 교수의 과제 공지, 데이터 형식과 지표, 검증·제출 방식, 팀 규모, GPU, 외부 서비스 및 사전학습 모델 허용 여부. 수업 자료만으로는 확인되지 않았다.
