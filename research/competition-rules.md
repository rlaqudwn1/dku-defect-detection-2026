# 제품 이미지 불량 탐지 대회 — 개요·평가·규정

2026-11-17 사용자가 대화에 전달한 대회 페이지 내용을 항목별로 옮긴 기록. 공식 페이지 URL과 게시일은 미확인이다. 아래 날짜는 전달일이며 수업일을 뜻하지 않는다. 원문 대화는 별도로 보존되며, 이 문서는 그 내용을 정리한 출처 기록이다.

## 대회 개요

제조업의 품질 유지와 불량품 조기 발견을 위해 제품 외관 이미지를 분석한다. 주제는 제품 이미지 기반 불량 탐지 AI 모델 개발이다. 제공되는 제품 이미지와 정상·불량 라벨로 모델을 학습하고, 테스트 이미지마다 불량일 확률을 예측한다.

- 주최: 단국대학교 단국AX부트캠프사업단, 단국앵커사업단.
- 운영: 데이콘.
- 참가 대상: 단국대학교 오픈소스 AI 응용 교과목 수강생.

## 평가

- 평가 산식: AUROC. 정상 제품과 불량 제품을 얼마나 잘 구분하는지 평가한다.
- Public Score: 전체 테스트 데이터 중 사전 샘플링된 30%.
- Private Score: 나머지 70%.
- 대회 평가는 Private Score 100%이며 종료 시 참가자가 선택한 제출 파일로 결정한다.
- 동점이면 해당 점수를 먼저 기록한 참가자가 상위다.
- 대회 직후 Private 랭킹은 최종 순위가 아니며 코드 검증 이후 수상자를 결정한다.

## 모델과 데이터 규칙

1. 연구 및 교육 목적으로 사용 가능한 오픈소스 모델을 사용할 수 있다. 대회 시작일 이전인 2026-11-15까지 공개된 사전학습 가중치를 사용할 수 있다. 라이선스를 준수하고 출처를 명시해야 한다.
2. 모델 학습에는 대회 제공 학습 데이터만 사용할 수 있다. 추가 외부 이미지 데이터셋 학습은 금지되며, 허용된 공개 사전학습 가중치는 사용할 수 있다. 테스트 정답을 유추하기 위한 원본 데이터셋 또는 외부 공개 라벨 조회·활용은 금지된다.
3. OpenAI API, Gemini API 등 외부 서버의 추론 결과를 제공받는 원격 모델 API는 사용할 수 없다. 모든 모델은 참가자의 로컬 또는 직접 관리하는 환경에서 학습·추론할 수 있어야 한다.
4. 제공 학습 데이터의 크기 조절, 회전, 반전, 색상 변환 등의 증강은 허용한다. 검증 및 테스트 데이터의 정답 정보를 이용한 학습은 금지한다.

## 코드 제출

전체 참가자는 최종 선택한 제출 파일을 재현할 수 있는 코드를 제출해야 한다.

- 기간: 2026-11-30(월) 10:00 ~ 2026-12-01(화) 10:00.
- 학습부터 테스트 추론과 최종 제출 파일 생성까지 확인할 수 있어야 한다.
- 제출 방법은 별도 공지.
- 언어: Python. 형식: .ipynb 또는 별도 지정 Python 소스코드.
- 데이터 입출력은 상대 경로 사용 권장. 코드·주석은 UTF-8.
- OS, Python, 주요 라이브러리 버전과 설치 방법을 명시.
- 오류 없이 동일한 형태의 예측 파일을 생성할 수 있어야 한다.
- 외부 모델과 사전학습 가중치 출처를 명시.

## 제출 유의 사항

- 1일 최대 3회 제출.
- 지정된 CSV 형식과 컬럼 구성을 준수하며 UTF-8을 사용한다.
- 정상적인 모델 학습·추론 과정으로 생성한 예측 결과만 제출할 수 있다.
