# 데이터 설명 — 사용자 전달 원문

2026-11-17 대화에서 사용자가 전달한 세부 설명. 공식 페이지 URL은 아직 기록되지 않았다. 아래는 전달된 내용이다.

> [세부 설명] 본 대회는 이미지를 보고 정상과 불량을 구분하는 과제입니다. 한 이미지에 제품이 여러 개 있어도 이미지당 불량 점수 하나를 제출합니다.
>
> train.csv
>
> image_path: train/ 내 이미지 파일명
>
> label: 0은 정상, 1은 불량을 의미합니다.
>
> train/ : 학습 이미지 폴더
>
> test/ : 평가 이미지 폴더
>
> sample_submission.csv : 제출 양식 파일입니다.
>
> image_path: test/ 내 이미지 파일명
>
> anomaly_score: 해당 이미지가 불량일 확률

따라서 양성 클래스는 1이며 이미지당 확률 하나를 생성한다. 객체별 라벨·마스크가 제공된 것으로 해석하지 않는다.
